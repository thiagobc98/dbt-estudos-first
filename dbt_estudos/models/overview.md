# Bem-Vindo ao projeto de dados
Este projeto DBT foi criado para atender a demanda de analise de dados do sistema de vendas da empresa, com intuito de extrair insights e informações valiosas para a tomada de decisão.

## Objetivos do Projeto
    - Melhorar a qualidade dos dados
    - Automatizar processos de transformação
    - Fornecer insights para o time de negócio

## Como navegar no projeto

Utilize o menu para explorar os modelos, sources, e a linhagem dos dados.
